# White Studio (وايت ستوديو)

مشروع تصميم فيديو احترافي متكامل بمستوى تطبيق **Video Star**، مصمم خصيصاً لمنصة iOS ومجهز بالكامل للرفع على GitHub وتحويله إلى ملف `.ipa`.

## المميزات الرئيسية:
1. **واجهة احترافية (Video Star Style):** تصميم داكن وأنيق مع شريط زمني مرن لإدارة المقاطع المتعددة (فيديو وصور).
2. **التحكم بالمدة والعزل:** إمكانية تحديد مدة كل مقطع وعزل الخلفيات أو تعديلها بدقة.
3. **استخراج الصوت:** ميزة استخراج الصوت من الفيديوهات المضافة بنقرة واحدة لاستخدامها في المشروع.
4. **التعرف التلقائي على الكلمات واللهجة:** سحب الكلمات من الأغنية تلقائياً مع مطابقة دقيقة للهجة الصوت الأصلية.
5. **الخطوط المخصصة:** دعم خطوط عربية احترافية مثل خط **MT Lombardia Scribble**.

---

## خطوات الرفع على GitHub والتحويل إلى `.ipa`:

### 1. رفع المشروع على GitHub:
1. قم بإنشاء مستودع جديد (Repository) على موقع [GitHub](https://github.com) باسم `white-studio`.
2. افتح الطرفية (Terminal) في مجلد المشروع ونفذ الأوامر التالية:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - White Studio iOS"
   git branch -M main
   git remote add origin https://github.com/اسم_المستخدم/white-studio.git
   git push -u origin main
   ```

### 2. بناء وتصدير ملف `.ipa` محلياً عبر Xcode:
1. افتح المشروع باستخدام برنامج Xcode على جهاز Mac.
2. اختر الجهاز المستهدف (Any iOS Device أو جهازك الشخصي المتصل).
3. من القائمة العلوي انتقل إلى: **Product > Archive**.
4. بعد اكتمال الأرشفة، انقر على **Distribute App** واختار **Development** أو **Ad-Hoc** لاستخراج ملف الـ `.ipa` مباشرة وتثبيته على هاتفك عبر AltStore أو Sideloadly أو 3uTools.
